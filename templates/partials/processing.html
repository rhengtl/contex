There is no progress bar here, and that is deliberate. The server does not report how far along a conversion is, so any bar drawn on this screen would be measuring nothing. What it shows instead is all true: which document is being read, how long it has actually been running, and an honest range for how long that usually takes. After two minutes it says so rather than pretending to be nearly finished.
